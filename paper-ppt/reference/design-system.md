# Design System — 论文汇报视觉规范

这套规范在 GroupKV 24 页实战中验证过：16:9、深蓝标题、青色方法、琥珀代价、红色风险。
目标是投影可读、远看有层次、换机器不跑版。

## 一、画布与栅格

- 尺寸：13.333 × 7.5 in（16:9）
- 页边距：左右 0.7；内容宽 11.93
- 标题区：y 0.38–1.47；内容区：y 1.78–6.90；页脚：y 7.08–7.5
- 双栏常用切分：左 6.2 / 右 5.4，中间留 0.3
- 卡片内边距：0.2–0.25；卡片间距：0.15–0.25
- 所有坐标用英寸，保留一位小数，便于对齐

## 二、配色（语义固定）

| 变量 | Hex | 用途 |
|---|---|---|
| NAVY | 0E2238 | 表头、深色结论页底色 |
| INK | 1B2A38 | 标题、强调正文 |
| BODY | 3D4B59 | 正文 |
| MUTED | 7A8896 | 图注、次要说明、页脚 |
| TEAL | 0E8F8F | 方法、计算、GroupKV 自身 |
| TEAL_DARK | 0A6E6E | 青色文字（浅底上） |
| TEAL_LIGHT | DDF0EF | 青色卡片底 |
| AMBER | C97A1E | 传输、预取、代价、警告 |
| AMBER_LIGHT | FBECD8 | 琥珀卡片底 |
| RED | B4433F | 暴露停顿、失败、关键局限 |
| RED_LIGHT | F8E4E2 | 红色卡片底 |
| BLUE | 2E5E8C | 基线/对照（区别于方法） |
| BLUE_LIGHT | E3ECF4 | 蓝色卡片底 |
| LIGHT | F4F7F9 | 无边框分区底 |
| BORDER | DDE5EC | 卡片描边、分隔线 |
| FAINT_LINE | E8EEF3 | 标题下细线、页脚线 |

规则：

- 一张图最多 3 个语义色；第 4 个用灰
- 红色只用于风险/失败，不做装饰
- 同一语义全篇同色，不因页面换色
- 深色页只用 NAVY 底 + 白/浅青文字

## 三、字体与字号

- 中文：Microsoft YaHei；西文：Segoe UI；公式：Cambria Math；代码：Consolas
- `style_run` 必须同时写 `a:latin` 与 `a:ea`，否则中文会回退成宋体

| 角色 | 字号 | 粗细 |
|---|---|---|
| 封面主标题 | 36–44 | Bold |
| 页面标题 | 24（长标题可 22） | Bold |
| kicker / 段落标签 | 9.5 | Bold，字距 160 |
| 卡片标题 | 11–12 | Bold |
| 正文/bullet | 10.5–12 | Regular |
| 密集双栏 bullet | 9.5–10.5 | Regular |
| 图表标签 | 9–10 | Regular |
| 图注/来源 | 8–8.5 | Regular / Italic |
| 大数字 | 32–40 | Bold |

投影底线：正文 ≥ 10.5pt；低于 9.5pt 只允许图注、图例、表格脚注。

## 四、容量估算（写文案前先算）

- 中文 1 字宽 ≈ 字号 × 0.0139 in（12pt ≈ 0.167 in）
- 英文 1 字符 ≈ 字号 × 0.0075 in
- 行高 ≈ 字号 × 1.15
- 可用行数 = 框高 / 行高；可用字数 = 框宽 / 单字宽

例：6.0 in 宽、12pt 中文 → 约 36 字/行；框高 2.0 in → 约 8 行。
超过就减字或拆页，不要先缩字号。

## 五、版式组件

### 页面骨架

```
┌ 0.7 ─────────────────────────── 12.63 ┐
│ ■ kicker                              │ 0.38
│ 标题（判断句）                         │ 0.66
│ ───────────────────────────────────── │ 1.47
│                                       │
│ 内容区                                 │ 1.78–6.9
│                                       │
│ ───────────────────────────────────── │ 7.08
│ 页脚文字                         页码  │
└───────────────────────────────────────┘
```

### 常用版式

1. **左文右图**：左 6.2 讲机制，右 5.4 放图；图下 0.2 放图注
2. **双卡片对比**：两张等高卡，中间 0.15 间隔；顶部各一个 pill 标签
3. **图表 + 洞察卡**：图占 7.2 宽，右侧 4.5 放 3 条"这张图说明什么"
4. **公式 + 量级条**：左公式推导，右用条形长度对比 2N vs 0.525N
5. **时间线/流水**：横向 4–6 个 box，箭头连接；下方一条 Gantt
6. **结论闭环**：Q1/Q2 卡片原样重排，右侧打勾/半勾 + 关键数字
7. **底部结论条**：`takeaway_strip`，全页只放一个结论，不叠加第二句

### 卡片规范

- 圆角 0.06；描边 0.9pt；无阴影
- 浅色底卡片不描边（LIGHT）
- 图标用文字/几何形状，不用 emoji（跨平台渲染不一致）

## 六、图表规范

- 必须原生图表（可编辑），不用截图贴数据
- 系列色：方法 TEAL，基线 BLUE 或 MUTED；第三项 AMBER
- 去掉 3D、渐变、图表边框；网格线用 ECF1F5，0.6pt
- 图例置顶，9.5–10pt；只有一个系列时删图例，写进标题
- 数据标签只标关键值，不全标；保留 1 位小数与论文一致
- 纵轴非零起点必须写进图注："纵轴从 0.70 起，用于放大差异"
- 缺失/OOM：值设为 `None` 让线断开，不要写 0；图注说明原因
- 单位与口径写进图注：batch、硬件、tok/s、GiB

## 七、表格规范

- 表头 NAVY 底 + 白字；行底白/LIGHT 交替
- 字号 9.5–10.5；首列左对齐，数值列居中
- 最优值加粗并用 TEAL_DARK；失败/OOM 用 RED
- 列宽按内容比例设，不要平均分
- 表格下方留 0.15 放"读法"一行

## 八、讲稿备注（每页必写）

2–4 句，固定三段：

1. 本页主张：一句话，和标题一致
2. 过渡：为什么下一页需要出现
3. 预判提问：听众最可能问什么，怎么答（或承认未解决）

## 九、不要做

- 不要渐变、阴影、艺术字、剪贴画
- 不要一页 3 个以上并列重点；宁可拆页
- 不要整段论文原文；转成短句和数字
- 不要用红色做强调色；红色只表示风险
- 不要 8pt 正文；不要把图注写得比正文还长
- 不要"谢谢"结尾；用讨论问题结尾
