# QA Checklist — 交付前必过的检查

渲染即真相。代码"看起来对"不算数，以 PowerPoint 导出的 PNG 为准。

## 一、生成前

- [ ] 提纲里每页有：所属段落、判断句标题、一句话内容、视觉形式、证据来源
- [ ] 每个上页数字都能在 `_deck_plan.md` 查到出处与口径
- [ ] 结论页的 Q1/Q2 与第 2 页完全一致（逐字）
- [ ] 批判页没有重复结论页的局限表述
- [ ] 最后一页有 2–3 个讨论问题

## 二、自动审计

```bash
py audit_layout.py deck.pptx
```

读报告时：

- `text-overflow`：文字纵向超出框，必须改文案/框高/字号（≥9.5pt）
- `text-out-of-slide`：文字跑出画面，必须修
- `out-of-slide`：形状出界；无文字的装饰出血 0.5in 内放行，带文字的形状严格
- 报告为空 ≠ 全部通过：它**不检查横向碰撞**，横向仍需拼图目检
- 无 PowerPoint 时只做边界检查，文字溢出仍需渲染后目检

## 三、渲染质检

```bash
py render_qa.py deck.pptx --out _qa --slides 1-24
```

按顺序看：

1. 4 宫格拼图，先扫全局：有没有明显空洞、错位、颜色跳变
2. 每段首页：标题区是否统一、段与段是否有节奏差异
3. 图表页：图例、标签、纵轴、单位是否可读
4. 表格页：行高、换行、最优值标注
5. 最密文字页：看原图，确认没有压线
6. 深色页：文字对比度、页码是否可见

只对以下页面看 1600×900 原图：图表、表格、双栏密集页、任何审计报警页。
不要整册逐页看原图，token 花在刀刃上。

## 四、逐页目检清单

- [ ] 标题是判断句，且和本页内容一致
- [ ] 一页只有一个中心思想
- [ ] 没有文字压到卡片边缘/分隔线/页码
- [ ] 没有两段文字互相覆盖
- [ ] 图表数据标签没有互相遮挡
- [ ] 图例没有压住数据
- [ ] 中文没有回退成宋体（对比标题与正文的字形）
- [ ] 页脚文字与本篇论文一致（不是上一个项目的残留）
- [ ] 页码连续，附录页编号正确

## 五、数字与口径

- [ ] 每个数字与论文原表一致（不要四舍五入到失真）
- [ ] 倍数写清是端到端还是单项（例如 48× 是 2K vs 96K 端到端）
- [ ] 平均值写清是算术平均还是几何平均
- [ ] OOM/失败没有被当成 0 画进图里
- [ ] 对比基线同稀疏率、同 batch、同硬件
- [ ] 近似值用"约/~"，不要伪装成精确值
- [ ] "论文未说明"的地方保持未说明，不补全

## 六、讲稿

- [ ] 每页都有 notes（含封面）
- [ ] 每条 2–4 句：主张 / 过渡 / 预判提问
- [ ] 没有把整页文字复制进备注
- [ ] 引用数字与页面一致
- [ ] 批判页的讲稿区分"作者说"与"我认为"

## 七、常见失败与修复

| 症状 | 原因 | 修复 |
|---|---|---|
| 文字溢出卡片 | 容量估少 | 先减字，再拆页，最后才缩字号（≥9.5） |
| 图表刻度报错 | `XL_TICK_MARK` 传 0 | 改 `XL_TICK_MARK.NONE` |
| OOM 折线连上 | 空值写成 0 | 用 `None` 断开 |
| 图例方块不显示 | 用 `□/▢` | 改 `■` 或画色块 |
| 纵轴截断误导 | 从 0.70 起 | 图注写明起点 |
| 上下标挤行 | baseline 太小 | 正文改文字表述 |
| 中文变宋体 | 只设了 latin | `style_run` 同时设 `a:ea` |
| 结论与批判重复 | 分工不清 | 结论只回答，批判只评价 |
| 双栏一高一低 | 没对齐 | 卡片等高，空侧放结论条/图 |
| 改一页重跑全部 | 没用 `--slides` | 只重导改动页 |
| 深色页页码看不见 | 页脚色太浅 | 深色页单独用浅色页脚 |
| 表格行高不够 | 字数多 | 减列/减字/加行高 |

## 八、迭代策略

1. 一次改完同类问题，不要改一页跑一次
2. 重跑 build（一次），再只导出改动页
3. 改完做一次整册拼图，确认没有回归
4. 连续两轮无新问题，停止；不要无限打磨

## 九、交付

- [ ] `.pptx` 能正常打开，无修复提示
- [ ] PDF 已导出且页数一致
- [ ] 临时文件（`_qa/`、`_paper_text.txt`、`_deck_plan.md`）已清理
- [ ] `build_deck.py` 与 `pptkit.py` 保留，用户可改数据重建
- [ ] 汇报给用户：路径、结构、如何改、备注在哪
